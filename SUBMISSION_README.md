# AR DETECTOR — решение КИБЕР-102

Мобильный прототип для предварительного осмотра промышленного оборудования от КСТ ЭНЕРГО ИНЖИНИРИНГ.

## Демонстрация

1. Установить app-debug.apk.
2. Открыть приложение и выбрать гостевой режим или войти в кабинет.
3. Открыть объект, запустить локальный анализ и сохранить результат в журнал.

## Возможности

- Локальное распознавание оборудования и признаков возможного дефекта через ONNX Runtime.
- Поддерживаемые классы каталога: насос, электродвигатель, клапан, трубопровод.
- Статусы: недостаточно данных, рекомендуется проверка, возможный дефект.
- Роли администратора и инженера могут добавлять и удалять объекты; гость просматривает и запускает анализ.
- Локальная карточка оборудования, параметры, наработка, обслуживание и журнал осмотров.
- Работа без сети после установки APK.
